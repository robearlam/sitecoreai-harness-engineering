## 2. Configure Generated Items

### 2.1 Update the Datasource Template (Image Gallery)

Do this before the rendering item, because the rendering references this template.

**Template path:** `/sitecore/templates/Project/harness-engineering/Image Gallery`

1. In Content Editor, navigate to the template and click **Builder**.
2. Delete every section and field cloned from Promo. The template must end up with one section and the two fields below.
3. Create a section named `Image Gallery Content`.
4. Add these fields:

   | Field Name | Field Type | Notes |
   |------------|------------|-------|
   | `Heading` | Single-Line Text | Optional. Rendered as an `h2`. When empty, no heading is rendered in the live page. |
   | `Images` | Multilist | Ordered Gallery Image items. Authored order is slide order. |

   > Field names are exact and case-sensitive. They must match `Heading` and `Images` in `imageGalleryTypes.ts`.

5. Set the **Source** of the `Images` field to:

   ```
   query:$site/*[@@name='Data']/#Gallery Images#/*[@@templatename='Gallery Image']
   ```

   > The `#Gallery Images#` segment contains a space, so it must be wrapped in `#` delimiters. Without them the query silently returns zero items. Replace `@@templatename='Gallery Image'` with `@@templateid='{GUID}'`, using the Gallery Image template's item ID, once the template exists. Sections 0.1 and 0.2 are complete at this point, so do it now. The selectable choices are the Gallery Image items in the `Gallery Images` folder.

6. Save the template. Keep `Standard template` as the base and remove any Promo-specific base templates.

### 2.2 Update the Rendering Item

**Item path:** `/sitecore/layout/Renderings/Project/harness-engineering/Image Gallery`

| Field | Required Value |
|-------|----------------|
| Component Name | `ImageGallery` (no space) |
| Data Source Template | `/sitecore/templates/Project/harness-engineering/Image Gallery` |
| Data Source Location | `query:$site/*[@@name='Data']/#Image Galleries#/*[@@templatename='Image Gallery']` |
| Rendering Contents Resolver | Leave at the default, as on the Promo Card Grid rendering. Do not set a custom resolver and do not add a GraphQL query. |

> **Critical:** `Component Name` must exactly equal the component map key, `ImageGallery`. This is the file base name, and the rendering item's name has a space but the component name does not. A mismatch renders blank.

> The Data Source Location query returns the Image Gallery items inside the `Image Galleries` folder as the selectable choices, not the folder itself. `#Image Galleries#` needs `#` delimiters because of the space. Replace `@@templatename='Image Gallery'` with `@@templateid='{GUID}'` using the Image Gallery template's item ID.

Also verify the rendering's **Rendering Type** and **Parameters Template** are those set by the script. The Parameters Template should be the copy created in section 1.
